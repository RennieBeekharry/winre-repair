Run this ONE command from the WinRE Command Prompt:

C:\Windows\System32\curl.exe -L "https://raw.githubusercontent.com/RennieBeekharry/winre-repair/main/repair.cmd" -o X:\repair.cmd && X:\repair.cmd

If it says it cannot resolve raw.githubusercontent.com, stop and send that exact error to ChatGPT. Do not type another diagnostic chain.

After the script runs:
- On success it automatically reboots after 15 seconds.
- On failure it does NOT reboot.
- The main log is C:\WinRERepair\logs\winre-repair-latest.log.
- If the WINREPAIR USB is present, upload <USB>:\RepairLogs\winre-repair-latest.log to ChatGPT if the repair does not fix booting.
